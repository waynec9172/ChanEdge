# ICT 研究結案（ICT P1/P2）

**結論：H-ICT 未通過。已登記的 19 個主實驗在 IS 全部沒過關卡 A′，晉級候選 0 個，沒有開 OOS。這份資料上找不到 ICT 結構的進場 edge。**

## 1. 範圍與方法

- **假設**：多空對稱的 ICT/SMC 結構策略，以 `ict_L7`（完整模型）代表。4H HTF 定方向，1H 用 swing、BOS、FVG∩OTE 建 zone，15m 觸區後等 LTF 觸發（MSS 或長影線）。濾網有 sweep、時段、資金費。多空規則完全鏡像，兩個狀態機各自獨立。
- **樣本**：只用 IS 2024-01-15 → 2025-06-30（2024-01-01 → 01-14 為暖機，丟棄）。幣池為每日 top-20，加上 `delist_rule` 和 `exclude_tradfi`。
- **口徑**：v2（每幣同時最多一筆，平倉後冷卻 4h）。成本為 taker 5bps、maker 2bps、slip 1bps，含資金費。
- **關卡 A′**（全部要達到）：
  - 淨 R ≥ 0.08/筆、PF ≥ 1.2、筆數 ≥ 150
  - 手續費 ×1.5 後淨 R > 0
  - 6 季中至少 5 季為正
  - 4 個鄰居參數組全為正
  - 週區塊 bootstrap（2000 次，seed 20261105）90% 下界 > 0
  - 多、空兩邊淨 R 各自 > 0
  - DSR 與滑價 ×3 只報告，不當關卡。
- **盲測漏斗**：在任何損益之前，L7 的 IS 事件數為 182，大於等於 150，所以進入 P2（見 `ict_funnel.md`）。
- **預算**：55/60。舊研究 36 個，加上 ICT 19 個。ict_rsv1–5 沒有啟用。DSR 的 N 取 55。
- **事先登記**：`research/plans/ict_phase1.md`，含附錄 A1–A3。A1.2/A2 處理的舊實驗 mismatch 已結案：IS 完全相同，差異只是龙虾/USDT 2026-10 的資金費漂移（見 `ict_legacy_mismatch.md`）。

## 3. 教訓

1. **LTF 觸發有用**。去掉 LTF 的 ict_loo_ltf 是所有 LOO 裡最差的（−0.124，多方 −0.214）。漸進序列中只有 L3→L4（加入 LTF）由負轉正（−0.033 → +0.018）。不過 L4 仍未過 A′。
2. **其他濾網沒有加分**。sweep、時段、新鮮度、funding 加進去之後，淨 R 沒有改善，反而變差或持平，同時筆數一路縮水。L7 比隨機基準好約 0.12R，但扣成本後仍然是負的。
3. **空方小幅為正，但不能當成發現**。L7 空方 +0.052（61 筆，PF 1.17），低於 0.08 的門檻；61 筆也遠少於單邊能自成檢定的筆數，而且 bootstrap 下界不可能為正。多數變體的空方為正、多方為負，但這是在 IS 多頭逆風下看完結果才注意到的模式，屬於事後觀察（見第 5 節）。
4. **改出場只會更差**。x_trail −0.093、x_notb −0.198，都比 L7 差。在這個進場下，換出場救不回來。
5. **與舊研究結論一致**。Phase 1/1b 的 Donchian 與纏論過濾在 10 組實驗中也沒有候選（最佳的 p1b_tr_4h_n20 v2 只有 +0.0105）。ICT 是第三類結構進場，結果同樣是：**在這份 top-20 永續資料上沒有可通過關卡的進場 edge**。

## 4. OOS 狀態

- 晉級候選 0 個，依 A1.3 第 6 點**不開 OOS**。全程沒有用過 `--oos`，`research/out/oos_log.md` 是 **0 bytes**。
- 理論上 OOS 期間 2025-07-01 → 2026-10-27 對 ICT 仍然沒看過。但它已經是 Phase 1b 停止條件下的保留資料，**不得**拿來驗證下面第 5 節的任何事後假設。

## 5. 明確聲明：只做空的後續

- 任何「只做空」或「只做 ICT 空方」的後續，都是**看過本 IS 結果之後才提出的事後假設**。事先登記第 2 節已預先排除用本 IS 改立單邊假設。
- 這類假設**不能**用本 IS（2024-01-15 → 2025-06-30）驗證，**也不能**用現有 OOS（2025-07-01 → 2026-10-27）驗證。
- 要做就必須：
  - 另寫一份新的事先登記檔，參數全部固定，並在看任何新資料之前 commit；
  - 只用 **2026-10-28 之後新產生的資料**（前推或紙交易），累積到事先登記的筆數或期間門檻後再判定。
- 在新登記 commit 之前，不得對 ICT 參數做任何調整或追加實驗。預算剩下的 5 個名額不用於 ICT。
